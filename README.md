# Sistema de Reservas de Salas de Gimnasio

## Descripción
Aplicación web para la gestión centralizada de reservas de salas en gimnasios, que permite a monitores, administradores y socios consultar disponibilidad y gestionar reservas sin solapamientos.

## Problema que resuelve
Actualmente, la gestión manual (papel, Excel, WhatsApp) provoca solapamientos, pérdida de información y dependencia de personas. Esta aplicación digitaliza y automatiza el proceso.

## Funcionalidades previstas
- Autenticación con roles (Monitor, Responsable, Admin, Socio).
- Calendario visual de disponibilidad.
- CRUD de reservas con validación de solapamientos.
- Gestión de salas y usuarios.
